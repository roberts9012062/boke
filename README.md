# 月言（Yueyan）· 月色微博客

> 写短句，收声音，偶尔录一点夜色。

「月言」是一个**短文 + 多媒体的轻博客社区**：以短句（≤2000 字）与图片、音频、视频为载体的安静社区。氛围关键词：安静、夜色、月光、慢节奏。设计依据 `boke.pen` 设计稿（294 画板，双主题 × 双端），全量走查纠偏完成。

## ✨ 功能全景

### 前台（访客 / 注册用户）
- **认证**：注册（自动用户名）/ 登录（邮箱或用户名）/ 静默刷新（JWT access 15min + refresh 7d）/ 登录限流 / **找回密码**（邮件，30 分钟令牌 + 60s 重发限制）
- **时间线**：全部/图/音/影过滤 + 滚动分页 + 推荐/关注流
- **创作**：文字 / 图片（≤9 张压缩）/ **音频（录音）** / **视频** 四形态发帖；标签（≤5）、可见性（公开/仅关注者/仅自己）、草稿箱（继续编辑）、**编辑已发布帖子**
- **帖子详情**：图片灯箱、音频/视频播放器、点赞/收藏（真实落库）、**举报**（6 预置原因）、**浏览埋点**（按日去重 + 匿名访客区分）
- **评论**：楼中楼 2 级 + **匿名评论**（昵称 + token 防刷）、评论点赞/删除、**AI 异步预审**（高风险自动进审核队列）
- **互动**：话题、搜索、通知（30s 轮询角标，今天/昨天/更早分组）、**私信**（会话/未读/已读/在线状态）、关注/粉丝/收藏、个人主页
- **体验**：冷月/薄雾**双主题**即时切换（跟随系统）、阅读字号/内容密度/减少动效/高对比/自动播放媒体外观设置、移动端 390px 底部导航、404/500/维护/无网络/引导状态页、用户协议/隐私政策/关于

### 后台（五级角色：超级管理员 / 编辑 / 作者 / 访客 / 受限访客）
- **仪表盘**：7 日指标 + 环比 + 互动趋势图 + 内容分布环形图 + **待处理块**（评论/举报/敏感词）
- **内容管理**：类型/状态 Tab + 分页 + 上下架/删除 + **后台编辑四画板**（文字/图片/音频/视频 + SEO 面板）
- **评论管理**：统计条（全部/待审核/今日新增/已屏蔽）+ 隐藏/恢复 + **AI 审核**
- **用户管理**：封禁（原因 + 永久/限时，台账）+ **调整角色**（五级弹层，自我保护）
- **内容治理**：审核队列（待处理/高风险统计 + AI 工单放行/删除）、敏感词（拦截/审核两级）、封禁管理
- **SEO 模块**：全局设置 / 健康度扫描（四卡片 + 趋势图 + 问题分布）/ **SERP 预览** / 批量修复 / 编辑页 SEO 面板（标题/描述/关键词/OG 图/**AI 摘要**）/ sitemap.xml + robots.txt
- **AI 设置**：OpenAI 兼容多供应商（deepseek/qwen/kimi/glm/openai，AES 加密 Key）/ 任务配置 / 用量统计 / **摘要·自动标签·评论审核** 三场景
- **插件系统**：GitHub 仓库驱动插件商城（安装/启用/卸载/兼容性校验）+ **钩子扩展框架**（6 插入点，故障隔离）+ 动态侧栏
- **数据报表**：统计卡 + 四维趋势（7/30 日）+ 待处理块 + **CSV 导出**
- **备份导出**：应用级 JSON/CSV/ZIP + 媒体库打包 + 过期清理 + 下载/删除
- **角色权限**：5 角色矩阵 + **权限域编辑**（14 个后台资源域，settings 持久化即时生效）
- 站点设置（含**维护开关**，全站 503 + 引导页拦截）、**审计日志**（角色/权限变更留痕）

## 🛠 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Go 1.26 + Gin + pgx v5（连接池）+ golang-jwt v5 + **Casbin（RBAC 域级策略）** + zap |
| 数据库 | PostgreSQL（26 表 + 12 个增量迁移，含匿名评论/角色/SEO/AI/浏览去重） |
| 前端 | Next.js 15.4 + React 19 + Tailwind CSS v4 + TypeScript（ESM） |
| 缓存 | Redis（限流/令牌黑名单/匿名身份，不可用自动降级） |
| 图表 | SVG 自绘（零依赖，双主题适配） |
| AI | OpenAI 兼容 Chat Completions（net/http 直连，零 SDK 依赖） |
| 插件 | Casbin 钩子系统 + GitHub 清单驱动（进程内实现，go-plugin 接口预留） |

## 🚀 快速开始

```bash
# 0. 前置：PostgreSQL（.env 配置连接）、Go 1.26+、Node.js 20+
cp .env.example .env   # 填写数据库连接与 JWT_SECRET

# 1. 初始化数据库（26 表 + 种子 + 管理员）
./scripts/init-db.sh
./scripts/seed-admin.sh

# 2. 启动双端（日志统一输出 logs/）
./scripts/dev-server.sh --daemon    # 后端 :8080
./scripts/dev-frontend.sh --daemon  # 前端 :3000

# 3. 停止
./scripts/stop-all.sh

# 其他脚本
./scripts/migrate.sh      # 增量迁移
./scripts/test.sh         # 后端测试
./scripts/build-frontend.sh  # 前端构建
./scripts/pen-inspect.sh  # 设计稿文案提取
./scripts/screenshot.sh   # Playwright 截图（视觉比对）
```

> 管理员初始账号：`admin@yueyan.site` / `Yueyan2026`（迁移 011 后角色为超级管理员；首次登录后请修改）。
> 邮件发送：`.env` 配置 `SMTP_*` 后自动启用真实发送；未配置时重置链接写入 `logs/`（开发模式）。
> AI：`.env` 可选配置 `AI_KEY_SECRET`（供应商 API Key 加密密钥，未配置回退 JWT_SECRET）；供应商 Key 在后台「AI 设置」填写。

## 📈 开发进度

**M1（基础闭环）✅**：双端骨架 + 双主题 → 认证 → 帖子/时间线/媒体 → 评论（楼中楼+匿名）→ 话题/搜索/通知/关注流 → 后台管理 → 移动端打磨与收尾。

**M2（进阶功能）✅ 8/8 + P1**：视频发帖 / 私信 / 举报·审核·敏感词·封禁 / 找回密码 / 可见性「仅关注者」/ 后台编辑表单 + 评论隐藏恢复 + 角色调整 UI / 匿名身份 Redis 化 / 全站维护开关 / **P1 浏览埋点**（按日去重 + 匿名访客区分）。

**M3（插件系统）✅**：GitHub 插件商城（安装/启用/卸载/兼容性校验）+ **钩子扩展框架**（6 插入点、故障隔离、启动恢复、前端动态侧栏）。

**M4（SEO + AI + 报表）✅**：SEO 模块（设置/健康度/SERP/批量修复）→ **AI SDK**（OpenAI 兼容多供应商 + 摘要/自动标签/评论审核）→ 数据报表 + 备份导出。

**M5（权限体系）✅**：五级角色 RBAC（superadmin/editor/author/visitor/restricted）+ 14 后台资源域访问控制 + 角色矩阵页（权限域编辑持久化）+ author 数据隔离 + restricted 前台拦截 + 审计。
