## 二、交付内容

### 1. .bpk 包格式（对齐 docs/architecture.md 6.5.6 + plugin-dev-guide 10.1）
```
{id}-{version}-{os}-{arch}.bpk（zip 封装）
├── manifest.json    # id/name/version/author/description/sdk（与 yueyan-plugin.json/Info 三处一致）
├── plugin.bin       # 插件二进制
├── pubkey.pem       # 许可证公钥（M3.5 预留，可空）
├── frontend/        # 前端扩展资产（M3.6 预留，可空）
└── checksums.json   # 以上全部文件 SHA-256（打包自动生成，不参与自身哈希）
```

| 环节 | 实现 |

## 四、踩坑记录（新窗口防踩坑）

1. **flag 包子命令**：`bp pack -plugin ...` 中 flag 包遇首个非 flag 参数（pack）即停止解析——需先剥离子命令再 Parse。
2. **Git Bash unix 路径**：脚本传 `$PROJECT_ROOT/...`（/o/... 形式）给 Go 程序会找不到文件——脚本内 cd 项目根后用相对路径。
3. **TempPath 目录**：`data/plugins/tmp/` 需先 MkdirAll（os.WriteFile 不自动建父目录）。
4. **打包清单格式**：cmd/bp 读取的是插件作者侧 `yueyan-plugin.json`（id/name/version/author/sdk），与商城聚合清单 plugins.json（{name, plugins[]}）不同——demo 插件需独立作者清单。
