## 二、全局会话退出密码版本号

### 实现内容
- **迁移 006**：`users.password_version` 列（默认 1）
- **JWT**：Claims 增加 `pv`（密码版本号），签发时写入（登录/注册/刷新共用 `issueTokenPair` 透传）
- **刷新校验**：`Refresh` 校验 `claims.PasswordVersion == user.PasswordVersion`，不匹配即拒绝（1001）——找回密码后旧 refresh 立即失效，实现「其他设备已退出」
- **重置自增**：`UserRepo.UpdatePassword` 重置密码时版本号 +1

### 实测记录（完整闭环）
1. mod_test 登录拿旧 refresh ✅
2. 请求重置 → 日志取 token → 重置为新密码（版本自增）✅
3. 旧 refresh 刷新 → **1001 拒绝**（版本号不匹配）✅
4. 旧密码登录被拒、新密码登录成功 ✅
5. 恢复原密码（60s 重发限制等待后二次重置）✅

### 差异记录
- access token（15 分钟窗口）不逐请求校验版本号（避免每请求查库），重置后旧 access 最多存活 15 分钟（可接受，已注释说明）

- **列表**：工单 DTO 增加 `cost_seconds`（已处理工单逐条展示备用）

### 实测记录
