## 一、后台编辑帖子表单（设计稿《后台编辑·文字/图片/音频/视频》四画板）

### 实现内容
- **后端**：`GET /api/v1/admin/posts/:id`（后台编辑详情：编辑区 + 发布信息 + 互动数据 + 操作所需全字段，不加浏览量、不校验可见性）；`PUT /api/v1/admin/posts/:id`（管理员编辑，不校验作者；状态 draft=保存草稿 / published=更新发布；封面策略：视频帖显式传 cover_url 换封面，图片帖取第一张图，其余保留原值；敏感词 forbidden 拦截与前台一致）
- **前端**：`/admin/posts/[id]/edit`（面包屑 + 标题行「状态徽标 / 预览 / 保存草稿 / 更新发布」+ 左栏四类型表单 + 右栏信息面板）；内容管理列表「操作」列新增「编辑」入口
  - 文字帖：标题 + 正文（字数 0/2000）
  - 图片帖：ImageUploader 多图（≤9）+ 图说/正文
  - 音频帖：AudioUploader（录音/文件）+ 说明
  - 视频帖：VideoUploader（更换视频）+ 封面预览/更换封面（上传图片）+ 说明
  - 右栏：发布信息（类型/状态/可见性/创建/更新）、互动数据（赞/评/览）、操作（下架/删除帖子）、SEO 面板占位
- **组件**：`components/admin/post-edit-form.tsx`（编辑区，forwardRef 暴露 save）、`components/admin/post-edit-panel.tsx`（右栏信息面板）

### 实测记录

## 五、全站维护开关 + 引导页拦截策略

### 实现内容
- **后端**：settings 新增 `maintenance_mode`（站点设置白名单）；错误码 6004「站点维护中」；中间件 `middleware/maintenance.go` 挂 /api/v1 组——维护开启时前台接口 503，放行 `/admin/*`、`/auth/*`、`/me`（后台登录态恢复与管理员登录流程依赖）、`/meta`；meta 接口新增 `maintenance_mode` 字段
- **前端**：
  - `MaintenanceGate`（挂根布局）：读 meta 判断维护状态，前台任意页面（含引导页/登录页/注册页）重定向 `/maintenance`；放行 `/admin` 前缀与维护页自身
  - api.ts：业务接口 6004 统一跳维护页（维护页与后台页面不跳，防循环）
  - 后台站点设置新增「维护模式」开关 + 开启提示
- **引导页拦截策略**：引导页不请求业务接口，由 MaintenanceGate 覆盖（实测 /onboarding 维护期间跳维护页）

### 实测记录
- 冒烟：开启（meta=on）→ /posts 6004 → 后台/登录/meta 放行 → 关闭恢复；32 项全过
- GUI：设置页开启 + 保存 → 前台首页/引导页跳「月言正在休整」维护页 → 维护期间后台设置页可访问 → 关闭后前台恢复
- **修复记录**：首测发现维护期间后台页面被弹维护页（AuthProvider 挂载时 /me 前台接口被拦 → api.ts 全局跳转，管理员登录流程同样中断）。修复：中间件放行 /me + api.ts 后台页面不跳转（双保险），重测闭环通过

### 差异记录
- 维护页文案（预计 02:00–04:00）沿用设计稿静态文案，未做「维护公告可配置」（YAGNI，后续需要再加 settings 字段）
