# 全站动效-验收报告

> 批次：全站丝滑动效改造（读取展示 / 鼠标悬停 / 点击 / 滚动 四大类交互动画）
> 完成日期：2026-08-13
> 技术路线：纯 CSS 动画体系（Tailwind v4 `@theme` + `@keyframes`）+ 2 个轻量 React 工具（零新依赖）

---

## 一、目标与结论

为全站补齐丝滑动画交互，覆盖「读取页面展示、鼠标移动选中、鼠标点击、滑动」四类场景。方案采用纯 CSS 动画体系，未引入任何第三方动画库，构建体积不变，并完全兼容现有「减少动效」开关（`data-motion="reduced"`）。

**结论：验收通过。** 生产构建成功，前后端启动正常，双主题（冷月/薄雾）× 桌面/移动 全量截图成功，无运行时 / 水合错误。

### 2. 四大交互场景落地

#### 2.1 读取页面展示（加载/进场）
- 路由切换/首次进入：`template.tsx` 全站 fade-up 入场（0.45s，一次性）。
- 骨架屏：`post-card-skeleton.tsx` 由 `animate-pulse` 升级为 `.skeleton-shimmer` 渐变扫光（减少动效时退化为静态底色）。
- 头像图片：`ui/avatar.tsx` `onLoad` 后淡入（避免图片晚到突兀闪现）。

#### 2.2 鼠标移动选中（hover）
- 帖子卡片：hover 轻浮起（`translateY(-2px)`）+ 阴影/描边加深 + 卡片内图片微放大。
- 用户卡片、草稿卡片：hover 描边/阴影过渡。
- 热门话题骨架条、主题切换图标：hover 呼吸/旋转。
- 移动端底部导航 Tab、桌面导航链接/搜索框/发帖按钮：补齐过渡曲线与 hover 反馈。
- 全局按钮统一过渡曲线（覆盖 107 处 `transition-colors` 未设时长的场景）。

#### 2.3 鼠标点击（点击反馈）
- 全局 `button:active` 按压回缩（scale 0.98，松手回弹）。
- 点赞弹跳：帖子卡片 + 评论区爱心 `animate-pop`（scale 1→1.25→1，320ms）。
- Tab 滑动胶囊：`feed-tabs.tsx` 重写为绝对定位胶囊指示器（`left/top/width/height` 平滑滑动到选中项）。
- 发帖按钮（桌面/移动）按压回弹。

#### 2.4 滑动（滚动）
- 滚动进场：`Reveal` 组件包裹主要列表项 —— 首页时间线、搜索结果、用户主页、话题帖、草稿、收藏（含滚动加载更多的新卡片）。
- 音频播放进度条：宽度过渡（播放/跳转更顺滑）。
- 平滑锚点滚动（`html[data-motion="normal"]`）。

## 三、验证结果

1. **生产构建**：`scripts/build-frontend.sh` 三次执行均成功（TypeScript + Tailwind 编译校验通过）。
2. **运行时**：`scripts/dev-server.sh` + `scripts/dev-frontend.sh` 启动，`/` 与 `/healthz` 均 200，前端日志无 error / hydration / exception 告警。
3. **视觉回归**：`scripts/screenshot.sh` 全量截图成功（首页/主题设置/登录/收藏/粉丝/后台仪表盘/404/引导 × 双主题 × 桌面/移动）。
4. **动画产物**：编译后 `layout.css` 确认包含 `@keyframes fade-up/pop/shimmer`、`animate-fade-up`、`animate-scale-in`、`skeleton-shimmer`、`motion-ready` 等。
5. **减少动效兼容**（代码级复核）：
   - `data-motion="reduced"` 全局规则（`globals.css`）强制关闭所有 transition/animation（`!important`），纯 CSS 方案天然满足。
   - 滚动进场隐藏规则显式限定 `[data-motion="normal"]`，减少动效下内容不被隐藏。
   - 骨架屏扫光在减少动效下降级为静态底色。

## 四、已知权衡（记录）

1. **页面入场与固定定位的瞬态**：`template.tsx` 的 fade-up 在 0.45s 动画期间对祖先施加 `transform`，会短暂改变内部 `position: fixed` 元素（移动端底部导航）的包含块；动画结束态为 `transform: none`，稳态定位完全正常。属一次性瞬态，截图（1.8s）均在稳态，无残留影响。如需彻底消除，可将页面入场改为纯 opacity，代价是失去上移层次感——当前方案优先保留设计层次。
2. **动画不落入截图等待窗口**：全部动画 ≤0.5s 且一次性（除骨架屏扫光为加载占位专用循环），不影响 `screenshot.mjs` 的 1.8s 等待策略与后续视觉回归稳定性。
