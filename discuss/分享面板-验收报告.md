## 实现内容

### 组件 `components/share-panel.tsx`（对齐设计稿 D/M 双端，三视图切换）
- **菜单视图**：分享帖子 + 标题 + 作者 · 话题 + 四宫格 + 链接预览/复制
- **二维码视图**：点击「二维码」→ 生成链接二维码（qrcode 库，260px）→ 展示 + 「保存二维码」（下载 PNG）+ 返回
- **海报视图**：点击「生成海报」→ canvas 绘制冷月夜色海报（800×1120）→ 预览 + 「保存海报」（下载 PNG）+ 返回
- 复制链接（clipboard 真实）；私信好友跳转消息中心（转发选人流程后置，差异记录）

### 核心工具 `lib/share.ts`（纯函数）
- `qrDataUrl`：二维码生成（qrcode ^1.5.4，新依赖，走 scripts/setup-frontend.sh 安装）
- `drawSharePoster`：海报绘制——冷月渐变背景 + 月亮装饰 + 品牌 + 标题（display 字体，2 行截断）+ **图片区（图片帖：最多 3 张，单图自适应 / 多图网格裁切填充，加载失败自动跳过）** + 正文（8 行换行截断）+ 分隔线 + 作者·话题 + **底部内嵌二维码** + 链接
- `downloadDataUrl`：dataURL 下载（a[download]）
- 新增依赖：`qrcode ^1.5.4` + `@types/qrcode ^1.5.5`

### 入口接入
- 帖子详情页：互动条「分享」按钮（传完整正文 + 图片媒体 URL）
- 帖子卡片：互动条分享按钮（传摘要 + 图片媒体 URL）
