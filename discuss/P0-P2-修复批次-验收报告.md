## 实现内容

### P0 · 功能缺失

1. **注册开关失效**：`allow_register` 只存不校验。`AuthService` 注入 `SettingRepo`，`Register` 校验 `allow_register != "false"`，关闭时返回 403「当前站点已关闭注册」（读取失败默认开放，与站点信息回退策略一致）
2. **评论开关失效**：`comment_open` 同上。`CommentService` 注入 `SettingRepo`，`Create`/`Reply` 入口校验（开关先于目标查询，避免泄露评论存在性）
3. **删媒体残留死引用**：`media_ids - $1::text` 对数字 JSONB 数组永不命中。改为 `jsonb_array_elements ... WITH ORDINALITY` 按值过滤重聚（保序、去全量）
4. **最后一个超级管理员可被降级/封禁**：新增 `UserRepo.CountByRole` + `AdminService.guardLastSuperadmin`——目标为 superadmin 且现存仅 1 名时拒绝（3002）；覆盖封禁（无自我保护）与降级两条路径

### P1 · 体验 / 信息泄露

5. **公开资料泄露运营角色**：`GetProfile` 非本人视角仅保留 superadmin（设计稿主页「站长」徽章有意公开），editor/author 等角色对外隐藏
6. **受限访客可上传媒体**：`POST /media` 补挂 `RequireNotRestricted`（与发帖/评论/私信拦截对齐）
7. **首页左栏假身份**：`user-card.tsx` 接入 `useAuth` 真实资料与统计（帖子/获赞/话题，≥1000 缩写 1.2k 形态），未登录保留设计稿占位
8. **热门话题假数据 + 死链**：`hot-topics.tsx` 接入真实话题接口按帖数降序取前 4；链接 `encodeURIComponent`（与话题列表页一致）；加载骨架 + 空态，不再伪造数据
9. **编辑帖子 SEO 面板不回填**：`PluginSlot` props 为挂载时快照——compose 页编辑模式待详情回填完成（`editLoaded`）后再挂载插件；顺带修复 `collectMediaIds` text 分支兜底携带残留音频的 BUG

### P2 · 健壮性 / 技术债 / 占位功能补全

10. **启动早退路径 nil panic**：`cleanup` 闭包 `pluginManager` 判空后再 `Shutdown`（casbin/媒体初始化失败时未赋值）
11. **敏感词缓存并发竞争**：`forbiddenWords` + `sync.RWMutex`（高频读 + 后台增删整体替换）
12. **AI UpdateProvider 死代码**：删除弃用的 `exist` 读取
13. **私信轮询丢历史**：轮询返回最近一页按 ID 合并追加，不再整体替换（超 30 条会话旧消息丢失）
14. **审核队列无错误处理**：解决/驳回/放行/删除补 try/catch + 错误提示条，失败不更新本地状态
15. **帖子详情竞态 + SEO 输出残留**：请求加 `cancelled` 标志；`document.title` 与 robots meta 在 effect cleanup 复原
16. **媒体上传不走统一请求**：`request` 支持 FormData（不设 Content-Type 由浏览器带 boundary），`apiUploadMedia` 改走统一封装获得 401 静默刷新
17. **插件沙箱 postMessage 无 origin 校验**：仅接受同源消息；代理转发补 `Authorization` 凭证（此前恒 401，`authHeader` 从 registry 导出复用）
18. **通知已读 / 备份下载容错**：`apiMarkAllRead`/`apiMarkRead` 补 catch；`downloadFile` JSON.parse 容错（损坏缓存按无凭证处理）
19. **消息搜索 + 选中态**：搜索框真实过滤（昵称/账号）；切 Tab 后失效选中项自动清空
20. **注销账号（需求 3.9）**：后端 `POST /me/deactivate`（外键级联删除 + 媒体物理文件清理 + casbin 分组移除 + superadmin 保护）；前端弹层接真实调用 → 登出 → 跳登录页
21. **隐私页假按钮**：「下载我的数据」真实导出 JSON（资料 + 全部帖子 + 收藏 + 关注/粉丝，分页循环拉全量）；「管理黑名单」改诚实禁用态
22. **settings Tab 死导航**：profile/theme 页顶部 Tab（隐私/通知/安全）由「M2 上线」灰按钮改为真实 `Link`，五页互通
23. **话题「精华」置灰 Tab**：移除无功能的置灰项（需后端加精标记，后置）
24. **过时注释清理**：under-construction（已无导航指向）、trend-chart（浏览埋点 P1 已完成）、settings-layout、me 页消息中心、posts 详情评论区等 6 处

## 差异记录

- 「后台 RBAC 完全失效」为误报：casbin 默认 RoleManager 的 `HasLink` 对 `name1 == name2` 恒真，`g(role, role)` 自映射成立；`RequirePermission` 传角色主体可正常命中 p 策略（smoke_role 37 项断言为证），未改动
- 注销账号采用**硬删除**（设计稿文案「永久删除」）：外键全部 ON DELETE CASCADE 已具备，audit_logs 无外键故操作历史保留；superadmin 禁止自助注销
- 下载我的数据为**客户端聚合导出**（分页循环拉全量），未新增后端端点（KISS）；「管理黑名单」依赖服务端屏蔽体系，保持禁用诚实态
- 有意保留的后置项（非 BUG，随排期）：登录设备管理（M4）、修改用户名（M2）、AI 费用折算、真实支付渠道（模拟支付为设计决策）、插件数据服务空占位兜底、SMTP 未配置降级日志
- 新增冒烟脚本 `scripts/smoke-fixes.sh`（回归：开关/注销/超管保护），配套 `scripts/smoke-role.sh` 包装既有 M5 冒烟（满足「Run & Debug 走 scripts/」规范）
