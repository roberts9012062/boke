## 5.1 本阶段已处理工程问题（记录）

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| 1 | `next build` 与 dev server 混跑导致 `.next` 缓存损坏（Cannot find module / 500） | 生产构建会重写 `.next` 目录，dev 模式缓存失效 | 已恢复（删除 .next 重建）；规范：**build 前必须先 stop-all**，已写入 build-frontend.sh 注释提醒 |
| 2 | Windows 下 `stop-all.sh` 停不干净：3000/8080 端口残留监听 | `nohup npm run dev` 记录的 PID 是 bash/npm 包装进程，真实 node/server.exe 是孙进程，SIGTERM 无法覆盖 | 已修复：stop-all.sh 在 Windows（Git Bash/MSYS）下用 `taskkill /T` 杀进程树 + **按端口（3000/8080）反查监听进程终止**双保险；实测停止后端口全部释放 ✅ |
