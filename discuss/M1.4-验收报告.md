## 4. 本阶段发现并修复的问题

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| 1 | 公开接口无法识别登录用户（评论被当匿名） | 评论路由未挂鉴权中间件 | **新增 OptionalAuth（可选鉴权）**：有 token 注入身份、无 token 放行；评论/详情/列表全挂 |
| 2 | 楼中楼 replies 永远为空 | 顶层列表存 dto **值副本**，回复挂载改 map 指针，两者脱节 | 顶层改存指针，挂载后解引用（注释记录历史故障） |
| 3 | 匿名身份失效后永久卡死 | localStorage 旧 token 无效时 ensureGuest 永远返回旧值 | **失效自愈**：1001 时 clearGuest + 重新弹昵称层 |
| 4 | M1.3 隐藏缺陷：作者看不到自己的私密帖 | 详情接口未挂鉴权（viewerID 恒 0） | OptionalAuth 修复（实测作者 can_view=true / 访客 2002）✅ |

> 调试过程说明：浏览器自动化（IAB）的 `fill()` 不触发 React onChange 导致多次误判"提交失败"，改用真实键盘输入（cua.type）后全部通过——**非代码缺陷，已在报告中记录**。

## 7. 验收请求

请在浏览器验证（建议用**真实键盘输入**评论）：
1. **匿名评论**：退出登录 → 帖子详情 → 输入评论 → 弹昵称层 → 填昵称 → 提交 → 评论显示匿名昵称。
2. **楼中楼**：评论「回复」→ 输入 @提及 回复 → 展开/收起回复。
3. **点赞收藏**：登录 admin → 详情页点赞（♥）、收藏（🔖）→ 刷新保持。
4. **评论点赞/删除**：登录后评论点赞；自己的评论可删除。
