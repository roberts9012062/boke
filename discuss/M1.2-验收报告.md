## 1. 本阶段交付清单

### 1.1 后端（✅ 完成）

| 模块 | 文件 | 说明 |
|---|---|---|
| 数据模型 | `internal/model/user.go` | User 实体 + RegisterReq/LoginReq/TokenPair/UserProfile DTO |
| 数据访问 | `internal/repository/user.go` | pgx 查询（创建/按邮箱或用户名查询/统计），ErrNotFound 统一语义 |
| 审计 | `internal/repository/audit.go` | audit_logs 写入（登录/注册/登出留痕，架构 9.2） |
| JWT | `internal/auth/jwt.go` | access 15min + refresh 7d，HS256 防算法混淆，refresh 带 tokenID 可撤销 |
| 认证业务 | `internal/service/auth.go` | 注册（邮箱唯一/自动用户名/bcrypt）、登录（统一错误提示/限流）、登出（黑名单）、刷新 |
| 权限 | `internal/casbin/casbin.go` | Casbin RBAC 两级角色（admin/user），策略 g,admin,admin |
| 限流 | `internal/redis/ratelimit.go` | 登录限流 5 次/分/账号 + 令牌黑名单；**Redis 优先 + 内存兜底**（开发环境 Redis 不可用不降级安全） |
| 中间件 | `internal/middleware/auth.go` | RequireAuth（Bearer 解析/过期 1002）+ RequireAdmin（403） |
| 控制器 | `internal/handler/auth.go`、`user.go` | 参数绑定与响应组装（无业务判断） |
| 路由 | `internal/router/router.go` | /auth/*、/me、/users/:id、/admin/ping |
| 装配 | `internal/server/server.go` | DB/Redis 连接 + 依赖注入（handler → service → repository） |
| 种子 | `cmd/seedadmin` + `scripts/seed-admin.sh` | 管理员账号（幂等：已存在跳过） |

| 1 | 登出后 refresh 仍有效 | **Redis（192.168.6.33:6379）不可达**，旧实现直接降级放弃撤销 | 重写 ratelimit：Redis 优先 + **内存兜底**（语义一致）；实测登出撤销生效 ✅ |
