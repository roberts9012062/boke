## 三、当前运行方式（新窗口继续开发前必读）

```bash
# 启动双端（自动安装依赖）
./scripts/dev-server.sh --daemon    # 后端 :8080
./scripts/dev-frontend.sh --daemon  # 前端 :3000
# 停止
./scripts/stop-all.sh               # Windows 进程树完整终止

# 数据库迁移（增量，禁止改 schema.sql 已上线部分）
./scripts/migrate.sh

# 构建校验（自动先停服务，防止 .next 缓存损坏）
./scripts/build-frontend.sh

# 视觉比对截图（先启动双端；首次自动下载 chromium）
./scripts/screenshot.sh             # 输出 screenshots/ 与 UI设计/ 人工比对
```

### 关键约定
- 一切启停/构建走 `scripts/`，日志在 `logs/`，代码中文注释

- 文档：正式→docs/，讨论/验收→discuss/（M1.1~M1.7 验收报告已输出）
- 数据库变更：`db/migrations/00N_*.sql` + `scripts/migrate.sh`
- Go 文件 ≤400 行、前端 ≤300 行、每层 ≤8 文件（超出拆子目录，如 components/ui、components/admin）
