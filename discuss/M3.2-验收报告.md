## 一、解耦：HookDispatcher 接口 + 注册表（业务零侵入）

### internal/plugin/ 新包
- **hook.go**：钩子名常量（对齐文档钩子表：post.before_publish / post.after_publish / comment.before_save / comment.after_save / search.query / notification.send / admin.page）+ `Event{TraceID, ActorID, Payload}` / `Result{OK, Reason, Modify}` / `Handler` 签名
- **dispatcher.go**：`Dispatcher` 接口（Dispatch/Register/Unregister）+ `Registry` 实现：
  - 同步钩子串行执行，任一拒绝（OK=false）即阻断核心（对齐敏感词拦截先例）
  - **故障隔离**：handler panic（goroutine 内 recover）/ 2s 超时 / 内部错误 → 跳过该插件继续执行 + 错误回调（不拖垮核心）
  - 异步钩子后台执行、失败静默
- **业务 service 只依赖 Dispatcher 接口**（构造器注入），不感知具体插件——插件增删零侵入核心

### 单元测试（dispatcher_test.go，6 项全过）
拒绝阻断 / panic 恢复（修复：recover 必须在 handler goroutine 内，panic 不跨 goroutine）/ 超时隔离（100ms 自定义超时）/ 内部错误跳过且后续处理器继续 / 异步不阻塞 / 注销后不执行

## 二、扩展性：业务钩子接入（6 插入点）

| 钩子 | 类型 | 插入点 | 语义 |
|---|---|---|---|
| post.before_publish | 同步可拦截 | post.go Create + post_helpers.go UpdateByAdmin（敏感词拦截后） | 插件可拒绝发布 |
| post.after_publish | 异步 | post.go Publish（draft→published 路径） | 发布后通知 |
| comment.before_save | 同步可拦截 | comment.go Create/Reply（敏感词拦截后） | 插件可拒绝评论 |
| search.query | 同步可改写 | search.go 入口 | 关键词改写扩展搜索 |
| notification.send | 异步 | notification.go send | 通知渠道扩展 |
| admin.page | 同步占位 | admin.go Dashboard 组装后 | 仪表盘指标扩展 |

### 内置示例插件（builtin.go）：评论反垃圾
- `comment-anti-spam` 安装/启用 → 注册 comment.before_save 钩子：拦截含外链（http/https/www）评论，返回「评论包含外链，已由『评论反垃圾』插件拦截」
- **端到端实测**：基线放行 → 安装后拦截（2003）→ 正常评论放行 → 禁用后放行（钩子注销）→ 启用后恢复拦截 → 卸载后放行

## 三、兼容性：清单契约 + 安装校验 + 生命周期联动

### 清单扩展字段（已推送 yueyan-plugins 仓库）
- `core_version`（如 ">=0.1.0"，版本三元组比较）、`requires`（依赖插件）、`conflicts`（冲突插件）
- `nav`（侧栏入口声明：href/label/icon）、`settings_schema`（设置项：text/switch/select + key/label/default/options）
- 6 插件全部标注 core_version；stats-pro 标注 requires seo-optimizer；markdown-plus 标注 conflicts

### 安装校验（checkCompatibility）
- core_version 不满足（核心 0.1.0）→ 3001「要求核心版本 xx，请先升级」
- requires 未安装 → 3001「依赖插件 xx，请先安装」（实测：stats-pro 未装 seo 被拒 ✅）
- conflicts 已安装 → 3001「与 xx 冲突，请先卸载」

### 生命周期联动
- 安装/启用(running) → 注册钩子；禁用/卸载 → 注销钩子（精确按注册项）
- **启动恢复**：`SyncActiveHooks` 服务启动时按 DB running 状态重注册钩子（修复：重启后插件功能失效问题，实测重启后拦截恢复 ✅）
