## 二、顺带修复

1. **dispatcher 同步分支 Modify 丢弃 bug**（M3.2 遗留）：循环后直接 `return Result{OK:true}`——content.render/search.query 的改写从未生效——修复为收集最后一个非空 Modify
2. **槽位插件 API 客户端无凭证**（M3.6 遗留）：registry/壳页 makePluginApi 补 Authorization（插件 API 属 authed 组，此前必然 401）
