## 一、交付内容

一个基于 go-plugin 插件系统的「网易云音乐」独立插件，实现：站长登录网易云 → 插件获取真实播放地址 → 前端自研播放器（双主题适配）播放，访客无需登录。

| 模块 | 文件 | 说明 |
|---|---|---|
| 插件主程序 | `cmd/netease-music-plugin/main.go` | Info/Hooks/RegisterAPI + 自定义 API（登录/登出/状态/搜索/详情/取地址） |
| 网易云客户端 | `cmd/netease-music-plugin/netease/` | `weapi.go`（双层 AES-CBC + RSA 无填充）、`eapi.go`（AES-ECB + md5）、`client.go`（cookie 会话 + 登录态 AES 落盘 + 播放地址缓存）、`login.go`（eapi 手机号登录）、`song.go`（搜索/详情/取地址） |
| 前端后台页 | `cmd/netease-music-plugin/frontend/settings-page.js` | admin.page：登录表单 + 状态 + 搜索试播 |
| 自研播放器 | `frontend/src/components/music-ref-player.tsx` | 封面/歌名/歌手/进度条/播放按钮，双主题 CSS 变量 |
| 主进程配合 | `post-content.tsx` / `post-card.tsx` / `compose/music-embed.tsx` / `compose/rich-text-editor.tsx` | 音乐引用渲染 + 发帖搜索选歌 |

| 构建/清单 | `scripts/build-netease-music-*.sh` / `marketplace-repo/netease-music/` | 编译/打包 .bpk + 市场清单 |

## 二、技术要点（调研 + 实测）

1. **weapi 加密**：双层 AES-128-CBC + **RSA 无填充模幂**（左补零 128 字节，易错点：不能用 PKCS1v15）。
2. **手机号登录必须走 eapi**（`/eapi/w/login/cellphone`），weapi 版会触发 8821 行为验证码；扫码登录最稳（后置）。
3. **搜索接口**用 `/weapi/search/get`（`cloudsearch/get/web` 已失效返回 50000005）。
4. **播放地址** `/weapi/song/enhance/player/url/v1`，`expi=1200`（20 分钟），已做缓存 + 提前 60s 刷新。
5. **登录态**：`MUSIC_U` + `__csrf` AES-256-GCM 加密落盘 `data/plugins/netease-music/state.json`，重启自动恢复。

## 四、播放问题修复（2026-08-13 追加）

用户反馈点击播放报 `SecurityError`（跨协议）。根因与修复：

| 问题 | 根因 | 修复 |
|---|---|---|
| 点击播放报 `Media load rejected by URL safety check` | CSP `media-src 'self'` 阻止网易云 CDN 音频 | `next.config.ts` 放行 `https://*.music.126.net`（media-src + img-src，仅 https） |
| 网易云地址是 http（生产 https 会混合内容） | 接口返回 http CDN | 插件 `song.go` `toHTTPS` 转 https |
| 访客无法播放（按钮 disabled） | 插件 API 挂 authed 组，访客调 song-url 401 | 主进程公开端点 `GET /api/v1/music/netease-url?song_id=`（OptionalAuth，转发插件），`MusicRefPlayer` 改调此端点 |
| 详情页播放器被卸载（React 渲染冲突） | `createRoot` 与 `dangerouslySetInnerHTML` 混用 | `post-content.tsx` 重构为 DOMParser 拆分音乐引用 → React 树渲染（不再 createRoot） |

**验证**：访客态 + 登录态详情页 `/posts/75`，播放按钮 enabled，audio `readyState=4`（已加载可播放）、无 error、无 console 错误。免费歌匿名获取为 30 秒试听（`duration=30`）；站长登录后解锁完整播放（待站长账号验收）。
