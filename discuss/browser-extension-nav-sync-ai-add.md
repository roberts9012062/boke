# 方案：书签站点导航「同步」+ AI 添加站点（对齐 web 端）

> 讨论稿 · 对应开发：插件书签 v0.27.0 批次。前提：「导入站点导航」（navlinks.list 镜像）已打通。

## 1. 需求（用户口径）

1. 「导入站点导航」升级为**同步**：不仅手动可刷，还要自动保持最新；
2. 新增与 web 端「添加站点」一致的 **AI 添加新书签**：填地址 → 自动抓图标 + AI 识别名称/分类/标签/简介（模型可选、可手动重跑）。

## 2. 设计

### 2.1 同步站点导航

| 项 | 决策 |
|---|---|
| 手动入口 | 菜单项「🌐 导入站点导航」→ 改名「🔄 同步站点导航」（动作不变：镜像刷新原位替换） |
| 自动同步 | 打开书签页时：已连接站点 + 设置开关开 + 根级已存在「站点导航」文件夹 → 静默刷新（失败不打扰；**不无中生有**，首次仍需手动同步） |
| 开关 | `PluginSettings.autoSyncNav`（默认 true），设置面板「通用」区新增开关行 |

### 2.2 AI 添加站点（对照 web 端弹窗）

表单字段与 web 端一致：站点地址*、网站名字*、分类*（可输入新分类，datalist 提示**书签树现有分类**）、标签（≤10，逗号分隔）、简介（≤200 字）、图标预览 +「重新抓取图标」。

| 能力 | 插件端落地 |
|---|---|
| 图标抓取 | 复用 `media.transfer`：转存 `https://<域名>/favicon.ico` → 本站持久 URL 存 `BookmarkNode.icon`（扩展页面直接 fetch 第三方 favicon 会被 CORS 拦，经站点后端转存绕开且无防盗链） |
| AI 识别 | `ai.models` 取模型（默认第一个，可下拉切换）→ `ai.chat.stream` 聚合（0.26.1 教训：非流式带思考段且易截断）→ 宽松 JSON 解析（剥 `<think>`/代码围栏，截断时逐字段正则兜底，参照 ArticlePanel parseMeta 三级容错） |
| 自动触发 | 地址 blur 且名称/分类仍为空时自动识别一次；「✨ AI 识别」按钮可手动重跑 |
| 保存位置 | 「✨ AI 收藏」根文件夹（分类子文件夹）——与「站点导航」镜像隔离，同步刷新不覆盖 AI 添加的书签 |

### 2.3 顺手修复

`settings.ts sanitizeChildren` 未保留 `icon` 字段——读写一轮自定义图标即丢失，补上。

## 3. 文件规划

```
bookmarks/ai-recognize.ts   # 识别纯函数：prompt 构建 + 宽松 JSON 解析（新）
bookmarks/AiAddSheet.tsx    # AI 添加站点弹层（表单/AI/图标/保存）（新）
settings.ts                 # autoSyncNav 字段 + sanitizeChildren 保留 icon
SettingsPanel.tsx           # 「通用」区自动同步开关
BookmarksTab.tsx            # 菜单接线 + 挂载自动同步 + AI 弹层
BookmarkMenus.tsx           # 菜单项：✨ AI 添加站点 / 🔄 同步站点导航
```

## 4. 验证

- [ ] 同步：手动同步刷新/首次导入提示正确；自动同步仅在已有镜像时静默生效；关开关后不再自动
- [ ] AI 添加：填地址 blur 自动识别（名称/分类/标签/简介回填）；手动重跑；模型下拉切换
- [ ] 图标：抓取成功显示真图标；失败回退 favicon/默认；「重新抓取」可用
- [ ] 保存：「✨ AI 收藏/<分类>」正确归档；再同步站点导航后 AI 收藏不受影响
- [ ] 双浏览器走手册 §12 清单
