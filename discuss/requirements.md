## 1. 产品概述

### 1.1 定位

月言是**「月色微博客」**：以短文（≤2000 字）与多媒体（图片/音频/视频）为载体的轻博客社区。氛围关键词：安静、夜色、月光、慢节奏。核心体验循环：

```
浏览时间线 → 发现话题 → 阅读帖子 → 评论/点赞/收藏 → 创作发声（文字/图片/音频）→ 关注同好 → 收到通知回流
```

### 1.2 用户角色

| 角色 | 权限（MVP） | 说明 |
|---|---|---|
| 访客（匿名） | 浏览全部公开内容；**匿名评论**（自填昵称） | 无需注册即体验 |
| 注册用户 | 访客 + 发帖/草稿/编辑、评论、点赞、收藏、关注、私信（后置）、通知 | 注册：邮箱 + 密码 |
| 管理员（admin） | 注册用户 + 后台全部：仪表盘、内容、评论、用户、站点设置 | 种子账号初始化 |

### 1.3 范围声明（MVP In / Out）

- **In**：认证、时间线、发帖（文字/图片/音频）、帖子详情、楼中楼评论（含匿名）、点赞/收藏/关注、话题、搜索、通知、个人/他人主页、草稿箱、主题切换（冷月/薄雾）、后台（登录/仪表盘/内容/评论/用户/站点设置）、建设中占位页。
- **Out（后置）**：视频发帖（M2）、私信（M2）、举报/审核/敏感词/封禁（M2）、找回密码（M2）、插件系统与商城（M3）、SEO 模块（M4）、报表/备份（M4）。数据库结构已全部建好，后置功能直接启用。

## 2. 全局设计规范

### 2.1 双主题设计令牌

从 `月言 · Style Guide（Dark/Light）` 画板提取，前端实现为 CSS 变量：

| 令牌（示例） | 冷月（dark） | 薄雾（light） |
|---|---|---|
| `--bg` 背景 | 深蓝灰（夜色） | 雾白 |
| `--text` 主文字 | 月白 | 墨灰 |
| `--text-2` 次文字 | 灰蓝 | 中灰 |
| `--accent` 强调 | 月辉银 / 冷蓝 | 天青 |
| `--border` 描边 | 低对比 | 浅灰 |
| 字体 | 展示字体（display）+ UI 字体（ui） | 同左 |

- 切换方式：根元素 `data-theme="cool-moon" | "mist"`，即时生效，用户选择 localStorage 持久化；服务端 `settings` 提供默认主题。
- 开发时以 Style Guide 画板为准补齐完整令牌表。

### 2.2 布局规范

| 端 | 宽度 | 布局 |
|---|---|---|
| 桌面 D | 1400px 设计稿 | 三栏：左栏用户卡片/导航（约 260px）、中间内容流（自适应）、右栏热门话题（约 280px）；后台为左侧固定导航 + 主内容区 |
| 移动 M | 390px 设计稿 | 单栏 + 底部 Tab 导航（首页/搜索/发帖/通知/我的） |

- 响应式断点：`<768px` 移动布局；`≥768px` 桌面布局。
- 移动端底部导航为固定悬浮栏，发帖为中间凸起主按钮。

### 2.3 通用状态页（全局组件）

| 组件 | 触发场景 | 说明 |
|---|---|---|
| 加载骨架 | 列表/详情加载中 | 卡片骨架屏（头像/标题/正文占位） |
| 空状态 | 无数据 | 图标 + 主文案 + 次文案 + 操作按钮（如「去发第一帖」） |
| 404 / 500 | 路由不存在 / 服务异常 | 设计稿专页 |
| 维护中 | 站点开关 | 全站维护页 |
| 无网络 | 断网 | 检测 navigator.onLine + 重试 |
| 弹窗提示 / Toast | 操作反馈 | 成功/警告/错误三态 |
| 引导 | 首次使用 | 引导页（移动端） |

## 3. 前台需求

### 3.1 认证（注册 / 登录 / 登出）

| 项 | 需求 |
|---|---|
| 注册 | 邮箱 + 用户名 + 密码 + 确认密码；客户端校验（邮箱格式、用户名 2-20 字符、密码 ≥8 位含字母数字）；服务端二次校验；成功后自动登录并进入首页 |
| 登录 | 邮箱或用户名 + 密码；错误提示「邮箱或密码不正确」；成功后跳转原目标页 |
| 登出 | 头像菜单 → 登出，清 token 回首页 |
| 会话 | JWT access（15min）+ refresh（7d）；`/auth/refresh` 静默续期；401 时自动刷新一次 |
| 忘记密码 | **MVP 占位**：入口存在，提示「即将上线」，不发邮件（M2 实现） |
| 页面 | D/M 双端：登录、注册、忘记密码、邮件已发送、重置成功（后三者 M2 激活） |

**验收**：注册→登录→登出闭环；错误提示准确；刷新后会话保持。

### 3.2 首页时间线

| 项 | 需求 |
|---|---|
| 布局 | 三栏（见 2.2）；时间线卡片流 + 分页（滚动到底加载更多或分页按钮，开发时二选一与设计稿一致） |
| 过滤 Tab | 全部 / 图 / 音 / 影（影=视频 M2 后生效，MVP 显示但视频帖为空） |
| 帖子卡片 | 作者（头像+昵称+@账号+时间）、正文截断（显示 3-4 行 + 展开）、媒体预览（图片网格/音频播放条）、底部互动条（赞/评论数/收藏/分享） |
| 左栏用户卡片 | 头像、昵称、@账号、简介、统计（帖子 128 / 获赞 1.2k / 话题 36）；未登录显示「登录」入口 |
| 右栏热门话题 | 「热门话题」标题 + 话题列表（#话题名 + 帖数），点击进话题页 |
| 排序 | 最新发布在前（published_at DESC） |

**验收**：三种类型帖子正确过滤；分页无重复无遗漏；双端布局符合设计稿。

### 3.3 帖子详情

| 项 | 需求 |
|---|---|
| 头部 | 作者信息、发布时间、可见性标记（公开/私密）、关注/私信（后置）入口 |
| 正文 | 完整展示；文字帖展示全文；媒体帖内嵌播放/查看 |
| 媒体展示 | 图片：灯箱（点击放大、左右切换、ESC 关闭）；音频：播放条（播放/暂停、进度、音量）；视频（M2） |
| 互动条 | 点赞（计数）、评论（计数+锚点）、收藏（个人收藏夹）、分享面板（复制链接/二维码占位） |
| SEO 面板 | 单帖 SEO 面板（M4 激活，MVP 不展示 UI，字段入库） |
| 相关推荐 | 同话题帖子（P1，可后置） |

**验收**：灯箱/音频播放可用；点赞收藏即时反馈；私密帖仅作者可见（其他人 404/无权限）。

### 3.4 发帖中心（创作）

| 项 | 需求 |
|---|---|
| 类型 Tab | 文字 / 图片 / 音频 / 视频（视频 M2 置灰「即将上线」） |
| 文字 | 富文本输入框（纯文本+换行即可，MVP 不做 Markdown 渲染），字数统计 **0/2000**，超限禁止发布 |
| 图片 | 多图上传（≤9 张）、预览、删除、压缩（前端 canvas 压到 ≤1MB/张） |
| 音频 | 录音（浏览器 MediaRecorder，≤5 分钟）或上传音频文件（mp3/m4a/wav，≤20MB） |
| 标签 | 标签输入（`#` 前缀自动识别，≤5 个，每个 ≤20 字符）；已有话题自动补全（P1） |
| 可见性 | 公开 / 私密（仅自己可见）双选项（密码帖 M2） |
| 草稿 | 「草稿」按钮保存草稿（含媒体引用）；草稿箱可继续编辑或删除 |
| 发布 | 「发布」→ 校验 → 成功页（发布成功画板）→ 跳转详情；发布后跳转个人主页最新帖 |
| SEO 面板 | 发帖中心有 SEO 展开面板设计（标题/描述/URL 别名/收录）——**MVP 不展示，M4 激活**；字段入库预留 |
| 发布后 | 触发通知（粉丝）、进入时间线；内容含敏感词（M2 启用） |

**验收**：四类输入（文字/图片/音频）全流程可用；字数限制；草稿恢复；可见性生效。

### 3.5 评论（楼中楼 + 匿名）

| 项 | 需求 |
|---|---|
| 入口 | 详情页评论区（`评论 · 36` 计数） |
| 发表 | 输入框「写一条评论…」+ 发送；**无需登录**（开放评论） |
| 匿名身份 | 未登录用户发表时：首次弹昵称输入（可选，默认「匿名访客」+ 随机后缀），生成**匿名 token**（服务端签发，短期有效，防刷）；已登录用户直接显示账号身份 |
| 楼中楼 | 顶层评论 + 回复展开（「回复」按钮 → 子级列表）；楼层号（floor）；层级 MVP 限制 2 级（顶层+一层回复） |
| 评论操作 | 点赞（计数）、作者可删除自己的评论；管理员后台可隐藏（见 5.4） |
| 排序 | 顶层评论按时间正序（楼中楼语义），或按热门（P1） |
| 空态 | 「还没有评论，写下第一条」 |

**验收**：匿名评论全流程；楼中楼展开/收起正确；防刷（匿名 token 限频）。

### 3.6 话题系统

| 项 | 需求 |
|---|---|
| 话题页 | 列表：#话题名 + 帖数（`#月色随笔 328 帖`）；Tab：全部 / 热门 / 最新 / 关注 |
| 话题详情 | 头部（话题名、帖数、关注按钮）+ 帖子流（按最新） |
| 热门话题 | 首页右栏取帖数 Top N；话题详情页取全量 |
| 关注话题 | 关注后出现在「关注」Tab（P1，MVP 可仅展示 Tab） |
| 标签详情页 | 设计稿有「标签详情」画板——MVP 与话题页合并呈现 |

**验收**：帖子带 # 标签即进入话题聚合；帖数统计正确。

### 3.7 搜索

| 项 | 需求 |
|---|---|
| 范围 | 帖子标题、正文、标签（PostgreSQL 全文检索 + pg_trgm 兜底） |
| 入口 | 桌面：顶部搜索框；移动：底部导航「搜索」 |
| 结果页 | 帖子结果列表（复用卡片组件）+ 话题匹配提示（如「#月色随笔」）；空结果空状态 |
| 交互 | 防抖（300ms）实时搜索建议（P1）；回车/按钮提交完整搜索 |
| 无网络 | 断网提示（见 2.3） |

**验收**：关键词命中标题/正文/标签；搜索页双端可用。

### 3.8 通知

| 项 | 需求 |
|---|---|
| 列表 | 顶部 Tab：全部 / 赞 / 评论 / 关注 / 系统（各带未读数角标）；时间分组：今天 / 昨天 / 更早 |
| 条目 | 触发者头像+昵称、动作文案（「赞了你的帖子」「评论了你」）、帖子摘要、相对时间；点击跳转对应帖子 |
| 已读 | 「全部已读」按钮；单条点击自动已读；未读高亮（`3 条未读`） |
| 角标 | 顶部导航/移动 Tab 未读角标 |
| 通知类型 | 赞、评论、回复、关注、系统（M2 后增加：举报结果等） |
| 近 7 日 | 首屏「近 7 日」分区（设计稿），更早通知折叠 |

**验收**：互动产生通知；未读/已读状态正确；角标实时更新（轮询 30s，MVP 不做推送）。

### 3.9 用户主页

| 项 | 需求 |
|---|---|
| 个人主页（我的） | 头部：头像、昵称、@账号、角色徽标（站长）、简介、编辑资料按钮；统计（帖子/获赞/浏览 或 关注者/关注中）；Tab：帖子 / 媒体 / 赞过 |
| 他人主页 | 头部：头像、昵称、简介、统计；操作：关注/取关、私信（M2）；Tab：帖子 / 媒体 / 赞过 |
| 编辑资料 | 头像上传（本地存储）、昵称、@账号（唯一）、简介（≤100 字）；保存即时生效 |
| 粉丝/关注 | 列表页：粉丝、关注、收藏、黑名单（各自画板）；关注/取关操作 |
| 帖子/媒体/赞过 | 帖子 Tab：全部帖子（含草稿仅自己可见）；媒体 Tab：图片/音频网格；赞过 Tab：赞过的帖子 |
| 账号安全（M2 激活） | 密码修改、登录设备；MVP 占位 |
| 注销账号（M2 激活） | 流程确认；MVP 占位 |

**验收**：主页信息与统计正确；关注/取关同步；编辑资料保存生效。

### 3.10 互动（点赞 / 收藏 / 关注 / 分享）

| 项 | 需求 | 数据落点 |
|---|---|---|
| 点赞 | 帖子与评论均可赞；点击即时反馈（+1/取消）；未登录点击提示登录 | posts.like_count / comments.like_count |
| 收藏 | 帖子收藏；「收藏」列表页可取消 | user_relations(type=favorite) |
| 关注 | 关注用户/话题；关注流 = 关注用户的新帖 | user_relations(type=follow) |
| 分享 | 分享面板：复制链接、站内转发（M2）、二维码（P1） | — |
| 黑名单 | 拉黑后：对方不能评论/私信（M2 生效规则，MVP 仅存数据） | user_relations(type=blacklist) |

### 3.11 主题设置

| 项 | 需求 |
|---|---|
| 设置页 | 「主题设置」画板：冷月/薄雾卡片选择，预览效果 |
| 即时切换 | 全局 CSS 变量切换，localStorage 持久化；未登录也可切换 |
| 服务端默认 | settings.theme 决定首次访问默认主题 |
| 跟随系统 | P1：prefers-color-scheme 自动 |

**验收**：双主题所有页面一致可读；刷新后保持。

### 3.12 建设中占位（后置功能页面）

前台以下入口显示「建设中」占位页（设计风格一致：图标 + 「即将上线」+ 返回）：私信会话、举报、视频发帖、分享面板（可先做复制链接）、账号安全、注销账号、找回密码流程页。

## 4. 后台需求

### 4.1 后台入口与登录

| 项 | 需求 |
|---|---|
| 入口 | 前台底部/头像菜单「管理后台」（仅 admin 可见）；路径 `/admin` |
| 登录 | 独立「后台登录」画板；仅 admin 角色放行；与前台同 JWT 体系（校验角色） |
| 导航 | 左侧固定导航（见 4.7 全量清单）；顶部：站点名（月言 · 管理）、用户信息、返回站点 |
| 未授权 | 非 admin 访问 → 403 页/提示 |

### 4.2 仪表盘

| 项 | 需求 |
|---|---|
| 运营总览 | 卡片组：浏览（近 7 日 12.4k）、获赞（1.2k）、评论（328）、今日新帖（86）——各带较上周环比（+8% 等）；「3 待审」徽标（M2 审核启用后） |
| 图表 | 近 7 日互动趋势（柱状/折线，前端图表库）；数据来源：posts 互动计数按日聚合（MVP 用简化统计：posts/notifications 表聚合） |
| 内容分布 | 文字 42% / 图片 31% / 音频 15% / 视频 12%（环形图） |
| 最近动态 | 最新操作/新帖列表 +「查看全部」→ 内容管理 |
| 刷新 | 手动刷新按钮；「更新于 刚刚」时间戳 |

**验收**：数据与库内真实数据一致；环比计算正确。

### 4.3 内容管理

| 项 | 需求 |
|---|---|
| 列表 | 表格：内容（缩略+标题摘要）、类型（文字/图片/音频/视频）、状态、互动（赞/评论）、发布时间、操作（编辑/上架/下架/删除） |
| 筛选 | 类型（全部/文字/图片/音频/视频）、状态（全部/已发布/草稿/已下架）、搜索（标题/标签）、排序（最新更新） |
| 统计条 | 全部 128 / 文字 64 / 图片 32 / 音频 18 / 视频 14 |
| 编辑 | 复用后台编辑画板（文字/图片/音频/视频四形态 + 文字·SEO 面板）；保存/发布 |
| 上下架 | 下架 = 前台不可见（status=已下架）；上架恢复 |
| 删除 | 二次确认；删除后级联（评论/标签计数） |
| 新建 | 「新建帖子」→ 发帖中心（以 admin 身份） |

**验收**：筛选/搜索/分页正确；上下架即时生效；删除有确认。

### 4.4 评论管理

| 项 | 需求 |
|---|---|
| 列表 | 评论内容、作者（含匿名）、所属帖子、时间、状态（可见/隐藏） |
| 操作 | 隐藏/恢复、删除（二次确认） |
| 筛选 | 状态、关键词搜索 |

### 4.5 用户管理

| 项 | 需求 |
|---|---|
| 列表 | 表格：用户（头像+昵称+@账号）、角色、帖子数、状态（正常/封禁/禁言）、注册时间、操作 |
| 统计条 | 全部用户 / 本周新增 / 活跃 / 已禁言 |
| 操作 | 封禁/解封（ban_records 记录、可设时限——MVP 支持永久+自定义时长）、角色调整（admin/user 两级） |
| 搜索 | 用户名/邮箱搜索 |

### 5.2 匿名评论迁移（开发前执行一次）

```sql
-- 开放评论无需登录：comments.author_id 允许 NULL + 匿名昵称字段
ALTER TABLE comments ALTER COLUMN author_id DROP NOT NULL;
ALTER TABLE comments ADD COLUMN IF NOT EXISTS guest_name VARCHAR(50) NOT NULL DEFAULT '';
ALTER TABLE comments ADD COLUMN IF NOT EXISTS guest_token_hash VARCHAR(64) NOT NULL DEFAULT '';
```

- 匿名 token：服务端签发短期 token（存内存/Redis，MVP 内存 + 哈希落库防刷），限频（同 token 1 条评论/分钟）。

### 5.3 种子数据补充

- 1 个管理员账号（admin / 初始密码首次登录强制修改——MVP 简化为初始化时写入，文档记录默认密码，首登提示修改）
- 示例话题：`月色随笔`、`夜读`、`城市声景`、`短片练习`（对应设计稿热门话题）

### 5.4 统计口径

- 仪表盘 7 日数据：按 `posts.created_at` / `posts.like_count` 等聚合；MVP 不做独立报表表，直接 SQL 聚合（数据量小）。

## 7. 验收标准（总）

1. **访客**：浏览时间线/详情、匿名评论、搜索、看话题、切主题——全流程可用。
