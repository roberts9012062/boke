## 5. 工程问题记录（已处理）

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| 1 | 发帖 6001 | 简单查询协议下 pgx 将 []byte 按 bytea 编码（\x…），JSONB 解析失败 22P02 | repository 将 media_ids 序列化为 string 传参（注释记录历史故障） |
| 2 | 5xx 无日志 | handler 未记录内部错误 | PostHandler 注入 logger，6001 自动留痕（path/request_id/error） |
| 3 | 测试数据乱码 | Git Bash curl 发送中文 body 为 GBK 编码 | 清理脏数据；后续测试用 python UTF-8 请求或浏览器操作 |

## 7. 验收请求

请在浏览器验证：
1. **发帖**：`http://localhost:3000/compose`（admin 登录态）→ 文字/图片/音频三种类型各发一帖 → 发布成功页 → 首页时间线可见。
