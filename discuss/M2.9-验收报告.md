## 一、媒体库（/admin/media）

### 实现内容（设计稿《后台媒体》）
- **后端**：
  - `GET /admin/media`（类型筛选/文件名搜索/分页 + **引用数**子查询）、`GET /admin/media/stats`（统计条）、`DELETE /admin/media/:id`
  - 删除为**事务**：解除帖子引用（`media_ids` 移除该 id + `cover_url` 清空）→ 删记录 → 删磁盘文件（`store.Remove` 新增，含路径穿越防护）
  - `MediaRepo.Stats/ListAdmin/Delete` + `Store.Remove`
- **前端**：统计条（全部文件/图片/音频/视频）+ 搜索 + 类型筛选 + 表格（文件[名+MIME+尺寸]/类型/大小/引用/上传/操作）+ **预览弹层**（图片大图/音频播放/视频播放）+ 删除（二次确认，被引用时提示影响）

### 实测记录
- 冒烟：统计条四项 ✅ 列表含引用数/文件名 ✅ 类型筛选 ✅ 上传临时媒体 → 删除（记录+引用+文件）✅
- GUI：侧栏激活、统计条/表格/预览弹层/删除按钮全部渲染 ✅
- **过程修复**：pgx 参数编码问题（`$1::text` 推断为 text 后 Go int64 无法编码 "cannot find encode plan"；多上下文推断 42P08/42P18）→ `$1` 传字符串 + `$3::bigint` 独立参数，最小复现验证通过

### 差异记录
- 文件名显示存储随机名（设计稿友好名如「霜序夜行.jpg」；原名未存 media_assets，需迁移加列后置）
- 音频/视频尺寸元信息未展示（设计稿 image/jpeg · 2048×1365 仅图片有宽高）

## 二、标签分类（/admin/tags）

### 实现内容（设计稿《后台标签》）
- **后端**：
  - `GET /admin/tags`（关键词/分页，按帖数降序）、`GET /admin/tags/stats`（统计条：全部/热门≥50/本周新建/未使用）、`PUT /admin/tags/:id`（重命名 name+slug 同步，重名冲突校验）、`POST /admin/tags/:id/merge`（合并：转移关联去重 → 重算计数 → 删源）、`DELETE /admin/tags/:id`（解关联+删除，事务）
  - `TagRepo.Stats/ListAdmin/Rename/Merge/Delete`
- **前端**：统计条（全部标签/热门/本周新建/未使用）+ 搜索 + 表格（标签[#名+@别名]/文章/热度[高≥50/中≥10/低]/更新/操作：编辑·合并·删除）+ 重命名弹层 + 合并弹层（选择目标标签）+ 删除（二次确认）

### 实测记录
- 冒烟：统计条 ✅ 列表 ✅ 建临时标签+关联 → 重命名 ✅ 合并（目标计数正确、源删除）✅ 删除 ✅
- GUI：侧栏激活、统计条/表格/编辑合并删除按钮全部渲染 ✅

### 差异记录
- 「分类」列（设计稿：情绪/日常等）MVP 无分类字段，以 #别名+描述形态呈现（tags.description 可用，分类体系后置）
- 重命名后帖子正文中的 # 文本不变（话题聚合以 tags 表为准，正文文本为展示层）
