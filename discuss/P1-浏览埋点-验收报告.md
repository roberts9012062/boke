## 实现内容

1. **迁移 012_views_dedup.sql**：post_views 加 `view_date DATE DEFAULT CURRENT_DATE`（自然日去重维度）+ 清理既有重复 + 唯一索引 `uq_post_views_daily (post_id, viewer_hash, view_date)`
2. **RecordView 改 upsert**：`INSERT ... ON CONFLICT (post_id, viewer_hash, view_date) DO NOTHING`——同人同日同帖只计一次（防刷新刷量）
3. **匿名访客区分**：viewerHash 扩展——登录 = SHA256(userID)；匿名带 guest token = SHA256("g:"+token)（复用前端匿名身份体系 readGuest()）；两者皆无降级空串
4. **链路透传**：GetDetail/handler 加 guestToken（`?guest_token=` query）→ 前端 apiPostDetail 自动携带本地 guest token

## 差异记录
- 去重口径为「自然日」（view_date），跨日重新计数；小时级/会话级去重后置
- 匿名访客的 guest token 为本地生成（设备维度），跨设备匿名无法合并（与匿名评论同一维度，可接受）
- 浏览统计与 posts.view_count 累计口径并存（IncrView 保留，详情展示用）
