## 一、实现内容

### 插件清单载体（GitHub 独立插件仓库）
- **已创建独立公开插件仓库 `roberts9012062/yueyan-plugins`**（按项目命名，非项目仓库）：仓库根目录 `plugins.json`（GitHub API 创建 + 推送，验证 200）
- **boke 项目仓库已移除 plugins.json**（不污染开源项目仓库，远程 404 验证）
- 清单格式 `{name, description, plugins[]}`，插件字段：id/name/version/category/price/installs/official/description/capabilities/repo_url
- 内置 6 插件（设计稿原样）：SEO 优化(免费/SEO·增长/官方)、评论反垃圾(¥29/安全/官方)、图片 CDN(免费/性能)、站点统计增强(¥49/分析)、Markdown 增强(免费/写作)、备份助手(¥19/运维)

### 后端
- `internal/ghclient`（新包，连接器类）：GitHub Contents API 拉取清单（token 认证 + raw 返回 + base64 兜底 + 路径注入防护 + 8s 超时）
- `PluginService`：Market（清单 + 已安装状态合并，5 分钟缓存）/ Install（新建 or 复用 uninstalled 记录重装——plugin_id 唯一约束）/ SetState / Uninstall / ListInstalled
- `PluginRepo`（plugin_instances 表）：Create/FindByPluginID/Reinstall/ListInstalled/SetState/Delete（软删 uninstalled）
- 接口：`GET /admin/plugins/market?source=`、`GET /admin/plugins`、`POST /admin/plugins/install`、`PUT /admin/plugins/:id/state`、`DELETE /admin/plugins/:id`
- settings 白名单加 `plugin_source`（用户自定义插件源持久化）

### 前端
- **插件商城页** `/admin/plugin-market`（设计稿完整）：
  - 插件源输入框（owner/repo，默认 roberts9012062/boke）+ 拉取按钮 + 当前源显示（GitHub 实时拉取）
  - 一级 Tab（全部/免费/付费/已安装）+ 二级类别 Tab（SEO·增长/内容增强/安全/性能/分析/写作/运维）+ 搜索
  - 插件卡片：名称 + 官方/类别标签 + 安装量 + 版本 + 描述 + 价格按钮（免费=安装；付费=购买并安装 · ¥xx）
  - 安装弹层（设计稿）：免费=能力清单+确认安装；付费=能力清单+永久授权+「支付 ¥xx 并安装」+ 模拟支付说明；Loading → 安装成功态
  - 已安装卡片：「已启用/已禁用」徽标 + 已装标记（对齐《已装SEO》画板）
- **我的插件页** `/admin/plugins`：已安装列表（名称/版本/状态徽标/来源/安装时间）+ 启用禁用 + 卸载（确认弹层 → 卸载成功态）+ 空态引导去商城
- 侧栏：插件 ▾ 二级子菜单「插件商城」「我的插件」激活

## 三、过程问题与修复
1. **plugin_id 唯一约束**（uq_plugin_instances）：卸载（软删）后重装违反唯一约束 → 新增 `FindByPluginID + Reinstall`（复用 uninstalled 记录恢复 running），实测重装通过
2. **测试脚本 urllib keep-alive**：PUT 后连续 DELETE 偶发 1001（连接复用请求头错乱，非应用问题）→ 测试脚本 DELETE 加 `Connection: close`；curl 全链路验证应用正确
