# 网易云音乐插件 · 方案设计

> 状态：**阶段 1 + 阶段 2 全部完成**（插件开发 + 发帖集成 + 自研播放器全链路验证通过）
> 日期：2026-08-13
> 目标：为月言博客开发「网易云音乐」独立插件——站长登录网易云 → 插件取真实播放地址 → 前端自研漂亮播放器（双主题适配）播放，访客无需登录。

---

## 一、需求背景

现状：发帖音乐内嵌用的是 QQ 音乐 / 网易云**官方外链 iframe 播放器**，UI 第三方无法定制、且网易云版权歌无法播放。

目标：改为**自研播放器 + 真实音频地址**，站长登录一次，访客直接播放。

## 二、技术可行性结论（已实测）

| 平台 | 取直链 | 结论 |
|---|---|---|
| 网易云 | 老接口 `outer/url` 已 404 下线；新接口 `/api/song/enhance/player/url` 需登录 cookie | **必须登录**（weapi） |
| QQ 音乐 | `getVkey` 免费歌匿名可拿（需国内 IP），当前环境 IP `invalidq` | 先做网易云，QQ 后置 |

## 三、架构设计

### 3.1 插件形态（独立插件，go-plugin 进程外）

```
cmd/netease-music-plugin/
├── main.go               # 插件主程序：Info/Hooks/RegisterAPI
├── yueyan-plugin.json    # 插件清单
├── netease/              # 网易云 API 客户端（独立子包）
│   ├── weapi.go          # weapi 加密（AES/RSA）
│   ├── client.go         # HTTP 客户端 + cookie 管理
│   ├── login.go          # 登录/登出/状态
│   └── song.go           # 搜索/详情/播放地址/歌词
└── frontend/
    ├── manifest.json     # extensionPoints + pages
    ├── settings-page.js  # 后台登录设置页（admin.page）
    └── player.js         # 自研播放器（或主进程组件）
```

### 3.2 后端插件自定义 API（`/api/v1/plugins/netease-music/**`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/login` | 手机号+密码登录（weapi），存 cookie |
| POST | `/logout` | 登出，清 cookie |
| GET | `/status` | 登录状态 + 用户昵称/头像 |
| GET | `/search?q=&limit=` | 搜索歌曲（发帖选歌） |
| GET | `/song/{id}` | 歌曲详情（歌名/歌手/专辑/封面） |
| GET | `/song/{id}/url` | 播放地址（实时取，带有效期） |
| GET | `/lyric/{id}` | 歌词（可选） |

### 3.3 登录态持久化

插件进程 cwd = 项目根，登录态（`MUSIC_U` cookie + `csrf_token`）AES 加密存到 `data/plugins/netease-music/state.json`（插件自有文件，主进程不托管，符合手册第 11 章）。

### 3.4 前端

- **后台登录页**：`admin.page`（`/admin/plugin-pages/netease-music/settings`）——登录表单 + 状态 + 歌曲搜索测试。
- **发帖集成**：搜索选歌 → 插入「音乐引用」节点（存 songid + 歌名/歌手/封面，不存 iframe）。
- **自研播放器**：读取音乐引用 → 调插件 API 拿地址 → `<audio>` 自研 UI（复用 AudioPlayer 改造）。

### 3.5 音乐引用数据格式（发帖内容 → 渲染）

```html
<div data-music-embed="netease" data-music-kind="song"
     data-music-id="1357375695"
     data-music-title="海阔天空"
     data-music-artist="Beyond"
     data-music-cover="https://...jpg">
</div>
```

渲染端（详情页 `post-content` + 卡片 `post-card`）识别 `data-music-id` → 渲染自研播放器 → 调插件 API 拿地址。

## 六、风险与合规

- **weapi 逆向**：网易云 weapi 加密属非公开接口，可能随客户端升级变动；有现成开源实现可参考（NeteaseCloudMusicApi / Music163Api-Go）。
- **版权**：仅站长登录态获取**自己有权播放**的歌曲地址；版权歌（VIP/无版权）依然拿不到，需前端提示「版权受限」。
- **播放地址有效期**：`player/url` 返回的地址约 20 分钟过期（expi），需按需实时获取或缓存+过期刷新。
- **账号安全**：登录态加密落盘；敏感信息不进日志。
