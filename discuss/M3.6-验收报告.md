## 一、交付内容

### 1. 前端扩展点三件套（frontend/src/plugins/）
| 文件 | 说明 |
|---|---|
| `loader.ts` | 运行时加载器：`fetchManifest`（扩展点声明缓存）+ `loadModule`（fetch JS 文本 → **Blob URL + 动态 import**（webpackIgnore 跳过打包器解析）→ ESM 默认导出 register；模块缓存同插件只加载一次）+ `clearPlugin`（停用/卸载清理缓存） |
| `registry.ts` | 槽位注册表（单例）：`mountSlot(pluginId, slot, el, user)`（声明匹配 → 模块加载 → register(ctx) 挂载 → 记录清理函数）+ `unmountPlugin`（精确清理挂载内容与缓存）；ctx.api 受限客户端（仅插件自定义 API 域） |
| `sandbox.ts` | iframe 沙箱（复杂插件基础）：iframe 挂载 + **postMessage 代理协议**（init 下发用户信息 / api 请求转发主站 / api-result 回传；复用登录凭证） |

### 2. 槽位组件与 4 个注入点（components/plugin-slot.tsx）
| 槽位 | 注入位置 |
|---|---|
| theme.header | components/desktop-nav.tsx（ThemeToggle 旁） |
| post.footer | app/posts/[id]/page.tsx（评论区后） |
| comment.footer | components/comment-section.tsx（评论区底部；**差异记录**：文档为单条评论下方，先挂列表底部） |
| admin.menu | app/admin/layout.tsx（侧栏插件菜单区，与 M3.2 动态 nav 链接共存） |

挂载流程：公开接口取 running 插件扩展清单 → 拉 manifest → 动态加载模块 → register(ctx)（ctx.user 脱敏 / ctx.api 受限）；卸载时执行清理函数。

### 3. 后端 assets 静态服务
- `GET /plugin-assets/:id/*filepath`（公开，独立前缀避免与 /api/v1/plugins/:id 通配冲突）
- 安全：pluginID 白名单（binstore.Dir）+ URL Clean + 平台路径前缀校验（防穿越）；资源安装时 checksums 全量校验（落盘即可信）；目录访问默认 index.html（iframe 入口）
- `GET /api/v1/plugin-extensions`（公开接口：running 且含 frontend/manifest.json 的插件清单——前台未登录页面可用，避免 admin 接口 401）

### 4. cmd/bp 与 demo 前端演示
- cmd/bp 新增 `-frontend <dir>`：递归收集目录入包（frontend/ 前缀）
- demo 插件 frontend/：manifest.json（post.footer 声明）+ index.js（ESM register 渲染「演示插件 · 文章页脚扩展」卡片）+ style.css
- next.config.ts 补 `/plugin-assets` 代理（页面运行时加载）

## 三、踩坑记录（新窗口防踩坑）

1. **公开接口必要性**：前台页面（帖子详情）未登录——插件扩展清单不能走 admin 接口（401）——需公开接口 `/plugin-extensions`（running + frontend 资产过滤）。
2. **Gin 路由冲突**：`/plugins/extensions` 与 `/plugins/:id` 参数段冲突（panic）——独立前缀 `/plugin-extensions`（与 plugin-oauth 同思路）。
3. **Next 代理**：`/plugin-assets` 需在 next.config.ts rewrites 中代理到后端（页面运行时 fetch 相对路径）。
4. **路径分隔符**：handler 中 URL 路径（正斜杠）与平台路径（Windows 反斜杠）混用会导致前缀校验失效——URL Clean 后 `filepath.FromSlash` 转平台路径再校验。
5. **Playwright 浏览器**：首次运行需 `npx playwright install chromium`（screenshot.sh 已有，独立脚本需手动装）。
6. **动态 import**：Blob URL + `import(/* webpackIgnore: true */)`——Next dev（webpack/turbopack）双支持。
