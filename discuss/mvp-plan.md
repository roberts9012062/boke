## 1. 设计稿解析：产品形态还原

对 `boke.pen` 294 个画板去重后，产品形态是**「月色微博客」**——不是传统长文博客，而是**短文 + 多媒体的轻博客社区**（首页文案："写短句，收声音，偶尔录一点夜色"）。

### 1.1 页面全景（双主题：冷月 Dark / 薄雾 Light；双端：D=1400px 桌面 / M=390px 移动）

| 分区 | 页面 |
|---|---|
| 前台-内容 | 首页时间线、关注流、帖子详情（楼中楼/灯箱/播放器/分享/可见性）、话题、话题详情、标签详情、搜索 |
| 前台-创作 | 发帖中心（文字/图片/音频/视频 四类型 + SEO 面板）、编辑帖子、草稿箱、发布成功 |
| 前台-用户 | 登录、注册、忘记密码、邮件已发送、重置成功、个人主页、他人主页、编辑资料、粉丝/关注/收藏/黑名单、账号安全、隐私设置、注销账号 |
| 前台-互动 | 消息、私信会话、通知、举报、举报成功、分享面板 |
| 后台 | 后台登录、仪表盘、内容管理、后台编辑（文字/图片/音频/视频）、媒体、标签、用户、角色、评论、站点设置、审核队列、举报工单、敏感词、封禁管理、审计日志、系统公告、数据报表、备份导出 |
| 插件/SEO | 插件商城、插件安装（免费/付费/Loading/成功）、插件卸载、SEO 设置、健康度、SERP 预览/弹层、问题详情/抽屉、批量修复 |
| 通用 | 404、500、维护中、无网络、空状态、加载骨架、引导、弹窗提示、细节组件、Style Guide（Dark/Light） |

### 1.2 关键设计要点（从画板文本还原）

1. **帖子四类型**：文字 / 图片 / 音频 / 视频——发帖中心 Tab 切换，正文上限 2000 字，带标签（`#月色`）、可见性（公开/私密/密码）、草稿、发布。
2. **首页布局**（1400px）：左侧用户卡片（头像/简介/帖子·获赞·话题数）、中间时间线（全部/图/音/影 过滤 Tab）、右侧热门话题（`#月色随笔 328` 等，带热度数字）。
3. **评论**：楼中楼嵌套；**开放评论，无需登录**（"写一条评论…（开放，无需登录）"、"匿名访客 · 昨天"）——需匿名评论身份机制。
4. **移动端**：底部 Tab 导航（首页/搜索/发帖/通知/我的），390px 设计。
5. **后台**：左侧导航（仪表盘/内容管理/评论/用户访客/站点设置/插件/插件商城/SEO 设置/健康度/SERP 预览）+ 顶部用户区；仪表盘含运营总览（近 7 日浏览/获赞/评论/新帖 + 环比）、7 日互动图、内容分布（文字 42%/图片 31%/音频 15%/视频 12%）、最近动态。
6. **插件商城**（设计已完整，属 M3）：搜索、分类 Tab（全部/免费/付费/已安装 + SEO·增长/内容增强/安全/性能/分析）、安装量、官方标签、免费/付费（¥29/¥49）按钮、安装 Loading/成功/卸载流程。
7. **SEO 是插件形态**（"SEO 优化 · v1.2.0 · 已启用"），发帖中心有 SEO 展开面板（标题/描述/URL 别名/收录 index-follow/OG 图片）——属 M4，但**发帖 SEO 字段的数据库结构 MVP 就要预留**。
8. **双主题**：Style Guide Dark/Light 各一套设计令牌（色板/字体），主题设置页可切换。

## 2. MVP 定位与原则

- **目标**：跑通「浏览 → 创作 → 互动 → 管理」的最小完整闭环，双主题 + PC/移动端可用。
- **原则**：YAGNI——设计稿中插件商城、SEO 模块、私信、举报审核、报表备份等**不做进 MVP**，但**数据库结构按架构文档已全部建好**，后续里程碑直接启用。
- **验收观感**：冷月/薄雾两套皮肤下的首页、详情、发帖、后台仪表盘与设计稿高度一致（像素级可后置打磨）。

## 3. MVP 功能范围

### 3.1 前台（访客 / 注册用户）

| 功能 | 说明 | 优先级 |
|---|---|---|
| 注册 / 登录 / 登出 | 邮箱 + 密码，JWT；MVP 不做找回密码（页面占位） | P0 |
| 首页时间线 | 帖子流（全部/图/音/影过滤）、分页加载、加载骨架/空状态 | P0 |
| 帖子详情 | 正文、图片灯箱、音频播放器、标签、点赞、收藏 | P0 |
| 发帖 | **文字 + 图片 + 音频**（视频 M2）；标签、公开/私密、草稿/发布 | P0 |
| 评论 | 楼中楼回复、点赞；**匿名访客可评论**（生成匿名身份）、登录用户显示头像昵称 | P0 |
| 个人主页 / 他人主页 | 帖子列表（按类型过滤）、关注/取关、粉丝/关注列表 | P0 |
| 话题系统 | 话题页（按 # 话题聚合帖子）、热门话题侧栏 | P0 |
| 搜索 | 标题/正文/标签关键词搜索 | P1 |
| 通知 | 互动通知（新评论/回复/关注/点赞），未读角标 | P1 |
| 关注流 | 关注用户的新帖流 | P1 |
| 草稿箱 | 保存草稿、继续编辑 | P1 |
| 主题切换 | 冷月/薄雾 CSS 变量即时切换，本地持久化 | P0 |
| 分享面板 / 举报 / 私信 / 视频 | 后续里程碑（页面可先占位 404/建设中） | 后置 |

### 3.2 后台（管理员）

| 功能 | 说明 | 优先级 |
|---|---|---|
| 后台登录 | 独立入口（/admin），仅 admin 角色 | P0 |
| 仪表盘 | 运营总览：7 日浏览/获赞/评论/新帖 + 环比、内容分布、最近动态 | P0 |
| 内容管理 | 列表（类型/状态筛选、搜索）、编辑、上/下架、删除 | P0 |
| 评论管理 | 列表、隐藏、删除 | P1 |
| 用户管理 | 列表、封禁/解封、角色调整（admin/user 两级 MVP） | P1 |
| 站点设置 | 站点名、描述、注册开关、评论开关、主题默认值 | P1 |
| 角色权限 | 完整 RBAC 页面后置；MVP 用 Casbin 两级角色（admin/user） | P1 |

### 3.3 基础能力（贯穿）

| 能力 | 方案 |
|---|---|
| 双主题 | CSS 变量设计令牌（从 Style Guide 提取色板/字号），`data-theme` 切换 |

## 5. 页面 → 接口映射（MVP 关键）

| 话题 | `GET /topics`、`GET /topics/{id}/posts` |

| 用户 | `GET /users/{id}`、`GET /users/{id}/followers`、`PUT /users/{id}/follow` |

## 6. 数据模型（复用已建表，无新增）

- 核心：`users`、`posts`（含 content_format、visibility）、`comments`（parent_id 楼中楼）、`tags`/`post_tags`、`media_assets`、`user_relations`（关注/收藏/黑名单）、`notifications`、`settings`
- **匿名评论**：`comments.author_id` 为 NULL + 新增匿名身份字段（设计稿"开放，无需登录"）→ 需 `ALTER TABLE comments ADD COLUMN guest_name`（小迁移，入库前执行）
- 预留：`seo_meta`（发帖 SEO 字段，MVP 不展示 UI）、`audit_logs`（后台操作写入，页面后置）

## 8. MVP 验收标准

1. **访客**：浏览时间线与详情、匿名评论、搜索、看话题。
2. **注册用户**：发帖（文字/图片/音频）、草稿、评论回复、点赞收藏、关注、个人主页、通知。
3. **管理员**：登录后台、看仪表盘、内容上下架/删除、评论管理、用户封禁、站点设置。
4. **体验**：冷月/薄雾即时切换；PC（1400）与移动（390）布局符合设计稿；加载骨架/空状态/404 齐备。
5. **质量**：全部启停走 `scripts/`、日志进 `logs/`、Go 文件 ≤400 行、中文注释。
